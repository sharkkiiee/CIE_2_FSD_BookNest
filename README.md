# BookNest — React + Express Book Management System

A CS3301 CIE 2 mini-project demonstrating React components, a class component, props, state, hooks, events, forms, React Router, responsive UI, Express REST APIs and frontend-backend integration.

## Structure
- `client/` — React + Vite frontend
- `server/` — Express backend and JSON data store

## Run locally
1. Install Node.js LTS.
2. From the BookNest root folder run: `npm install`.
3. Run: `npm run install-all`.
4. Run: `npm run dev`.
5. Open the Vite URL shown in the terminal (usually `http://localhost:5173`).

The Express API runs on `http://localhost:5000`.

## CIE 2 concepts demonstrated
- Reusable functional components
- `Stats` class component
- Props and parent-child communication
- `useState`
- `useEffect`
- Event handling
- Functional form handling and validation
- React Router pages
- Responsive UI
- Express CRUD API
- React ↔ Express integration
